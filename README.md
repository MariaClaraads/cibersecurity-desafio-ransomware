# 🔐 Laboratório de Ransomware

## 📌 Sobre o projeto

Laboratório prático realizado durante um curso da *DIO (Digital Innovation One)*, com o objetivo de compreender, em ambiente controlado, conceitos relacionados à criptografia de arquivos e ao funcionamento de técnicas utilizadas em ataques de ransomware.

A atividade foi desenvolvida exclusivamente para fins educacionais, permitindo compreender os riscos relacionados à indisponibilidade de arquivos e a importância de medidas de proteção e segurança da informação.

## 🎯 Objetivo

O objetivo deste laboratório foi compreender, de forma prática:

- O conceito de ransomware;
- O processo de criptografia de arquivos;
- O processo de recuperação de arquivos por meio da descriptografia;
- A utilização da linguagem Python em um laboratório de segurança;
- A importância da proteção e do backup dos dados.

## 🛠️ Tecnologias e ferramentas utilizadas

- 🐍 Python
- 🐧 Kali Linux
- 🔐 Biblioteca PyCryptodome
- 💻 Máquina virtual para realização do laboratório

## 🧪 Execução do laboratório

A atividade foi realizada em um ambiente controlado utilizando o Kali Linux e scripts desenvolvidos em Python.

Durante o laboratório, foi realizado um teste utilizando um arquivo de texto, permitindo observar as alterações no arquivo durante o processo de criptografia e posteriormente sua recuperação por meio da descriptografia.

## 📚 Aprendizados

Com a realização deste laboratório, foi possível compreender melhor:

- O funcionamento básico da criptografia de dados;
- A importância das chaves criptográficas;
- A relação entre criptografia e ataques de ransomware;
- A utilização do Python em atividades de cibersegurança;
- A importância de backups para recuperação de dados;
- A necessidade de utilizar ambientes isolados para testes de segurança.

## 🛡️ Boas práticas de segurança

O laboratório também reforça a importância de medidas preventivas contra ransomware, como:

- Manter backups atualizados;
- Utilizar soluções de segurança;
- Manter sistemas e softwares atualizados;
- Evitar arquivos e links suspeitos;
- Utilizar autenticação segura;
- Restringir privilégios de acesso;
- Manter os dados críticos protegidos.
